# HHAeXchange Maryland Daily Report — v0.6.0

Chrome extension: sets Received From/To to today, clicks **View Report** (never Generate), waits until the View window finishes drawing, then downloads **Excel (.xlsx)**.

## Download

**Direct zip:** https://github.com/bandhu-netizen/hhaexchange-maryland-daily-report/releases/download/v0.6.0/hhaexchange-daily-report-v0.6.0.zip

Or use **Code → Download ZIP** on this repo.

## Install

1. Unzip. You should get a folder named `hhaexchange-auto-report`.
2. Chrome → `chrome://extensions`
3. Turn on **Developer mode**
4. Remove any older Maryland Daily Report build
5. **Load unpacked** → select `hhaexchange-auto-report`
6. Stay logged in to Maryland HHAeXchange → click the extension → **Pull today’s report**

Does not store your HHAeXchange password.
